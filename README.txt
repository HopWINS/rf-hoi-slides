RF-HOI — research HTML slides

Open index.html in a modern browser. Keep the complete folder together.
The deck and its KaTeX fonts, artwork and evidence figures use local files.

28 English slides, 1600 x 900.
Left/Right or Page Up/Down: previous/next slide
P: pause/resume animations
O: overview; Escape closes it
F: fullscreen, where the browser supports it
Home/End: first/last slide
Touch screens: swipe horizontally

Editable files
index.html: slide content, selected takeaways and order
takeaways.json: wording reference for six selected takeaway pages; index.html contains the displayed text
styles.css: shared layout and current branding
model.js: ideal geometric RFID teaching model
scenes.js: shared polished RFArt and physical sensing examples
applications.js: motivating action/object sequence
story-scenes.js: collection-factor illustration
mechanisms.js: shared hand-proxy and semantic-expansion illustrations
challenge-scenes.js: challenge-led representation, clock, fusion and output diagrams
synthesis-scenes.js: coverage, shared meshes, radar ray tracing and RFID physics
research-figures.js: native vector redraw of approximately digitized Figure9b
narrative-scenes.js: causal process and evaluation scenes
evidence.js: fixed paper results, direct differences and new/seen-object tradeoff
slides.js: navigation, time, pause and deterministic capture
AUTHOR_NOTES.md: claim outline and whole-argument reviews
SOURCE_NOTES.md: exact conditions, source ledger and model assumptions
